# Tailor Point — Website

A premium, responsive business website designed for **Tailor Point**, a men's custom tailoring and suit-stitching business based on Gohana Road, Sonipat, Haryana.

The website showcases Tailor Point's tailoring services, craftsmanship, customer reviews, business story, gallery, pricing, location, working hours, and contact information.

## Website Features

* Premium luxury tailoring-inspired design
* Fully responsive for mobile, tablet, and desktop
* Custom suits and men's tailoring services showcase
* Service-wise WhatsApp enquiry buttons
* One-click Call and WhatsApp integration
* Sticky mobile Call/WhatsApp bar
* Customer testimonials
* Tailor Point business story
* Image gallery
* Transparent pricing section
* Google Maps location
* Business hours and contact details
* Instagram integration
* Smooth scrolling and subtle animations
* SEO-friendly structure

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Inline SVG
* Google Maps Embed
